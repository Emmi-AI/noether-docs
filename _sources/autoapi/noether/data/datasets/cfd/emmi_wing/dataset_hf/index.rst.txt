   Emmi-Wing dataset loaded from the HuggingFace subset.

   Uses the 248-case evaluation scan subset with its own train/val/test splits.
   The dataset can be auto-downloaded from HuggingFace using :func:`download`.

   :param dataset_config: Configuration for the dataset. See :class:`~noether.core.schemas.dataset.DatasetBaseConfig` for available options.
   :param filemap: FileMap object defining the mapping of data properties to filenames. See :class:`~noether.data.datasets.cfd.caeml.filemap.FileMap` for details.

   .. py:method:: download(local_dir)
      :staticmethod:


      Download and extract the HF subset to a local directory.

      Downloads ``scans.zip`` from HuggingFace, extracts the nested ``run_N.zip`` archives into ``<local_dir>/run_N/``
      directories, and cleans up the zip files.

      :param local_dir: Destination directory.

      :returns: Path to the extracted dataset root.
