.. py:function:: estimate_hf_repo_size(repo_id, repo_type = 'model', revision = 'main', extension = None)

   Estimate total size (bytes) of all files in a HF repo (model or dataset),
   optionally filtering by file-extension.

   :param repo_id: HF repo ID, e.g. "bert-base-uncased" or "user/my-dataset"
   :param repo_type: "model" or "dataset"
   :param revision: branch/tag (default "main")
   :param extension: if given (e.g. ".jsonl"), only count files ending with this

   :returns:

             - Integer value for the total size in bytes.

   Downloads a specific file from a HuggingFace repository into a local directory.
