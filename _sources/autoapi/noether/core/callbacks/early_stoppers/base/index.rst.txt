   Bases: :py:obj:`noether.core.callbacks.periodic.PeriodicCallback`


   Base class for early stoppers that is used to define the interface for early stoppers used by the trainers.

   :param callback_config: Configuration for the callback. See
                           :class:`~noether.core.schemas.callbacks.CallBackBaseConfig`
                           for available options.
   :param trainer: Trainer of the current run.
   :param model: Model of the current run.
   :param data_container: :class:`~noether.data.container.DataContainer` instance that provides access to all datasets.
   :param tracker: :class:`~noether.core.trackers.BaseTracker` instance to log metrics to stdout/disk/online platform.
   :param log_writer: :class:`~noether.core.writers.LogWriter` instance to log metrics.
   :param checkpoint_writer: :class:`~noether.core.writers.CheckpointWriter` instance to save checkpoints.
   :param metric_property_provider: :class:`~noether.core.providers.MetricPropertyProvider` instance to access properties of metrics.
   :param name: Name of the callback.
