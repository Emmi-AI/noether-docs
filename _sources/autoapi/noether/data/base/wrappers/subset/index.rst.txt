.. py:class:: SubsetWrapper(config, dataset)

   Bases: :py:obj:`noether.data.base.subset.Subset`


   Wraps the dataset with a noether.data.Subset using indices generated by the properties from the constructor.

   .. rubric:: Example

   .. code-block:: yaml

       dataset_wrappers:
           kind: noether.data.base.wrappers.SubsetWrapper
           start_index: 100
           end_index: 200

   :param config: The configuration to use. See :class:`~noether.core.schemas.dataset.SubsetWrapperConfig`
                  for available options.
   :param dataset: The dataset to wrap.

   :raises ValueError: If the input parameters are invalid.
   :raises RuntimeError: If no valid indices are provided.
