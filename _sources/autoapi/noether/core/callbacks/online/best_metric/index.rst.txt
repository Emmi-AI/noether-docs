.. py:class:: BestMetricCallback(callback_config, **kwargs)

   Bases: :py:obj:`noether.core.callbacks.periodic.PeriodicCallback`


   A callback that keeps track of the best metric value over a training run. For example, track the test loss of
   the epoch with the best validation loss to simulate early stopping.

   Initializes the BestMetricCallback

   :param callback_config: The configuration for the callback.
   :param metric_property_provider: The metric property provider to determine whether higher values are better.
   :param \*\*kwargs: additional keyword arguments provided to the parent class.

   .. py:method:: _periodic_callback(**__)

      Method that is invoked periodically in the defined interval of the `PeriodicCallback`. Child classes should
      overwrite this method to calculate metrics periodically during training and log them.

      :param interval_type: "epoch", "update", "sample" or "eval" indicating which interval triggered this callback.
      :param update_counter: UpdateCounter instance to access current training progress.
