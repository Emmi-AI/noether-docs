.. py:function:: get_supported_precision(desired_precision, device)

   Returns desired_precision if it is supported and backup_precision otherwise. For example, bfloat16 is not
   supported by all GPUs.

   :param desired_precision: The desired precision format.
   :param device: The selected device (e.g., torch.device("cuda")).

   :returns: The most suitable precision supported by the device.
   :rtype: torch.dtype


.. py:function:: is_compatible(device, dtype)

   Checks if a given dtype is supported on a device.

   :param device: The device to check compatibility.
   :param dtype: The data type to check.

   :returns: True if the dtype is supported, False otherwise.
   :rtype: bool
