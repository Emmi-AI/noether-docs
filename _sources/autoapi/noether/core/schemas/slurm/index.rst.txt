.. py:class:: SlurmConfig(/, **data)

   Bases: :py:obj:`pydantic.BaseModel`


   Configuration for SLURM job submission via sbatch.

   All fields are optional and default to None, meaning the cluster default will be used.
   This schema covers all sbatch directives available in SLURM.

   Create a new model by parsing and validating input data from keyword arguments.

   Raises [`ValidationError`][pydantic_core.ValidationError] if the input data cannot be
   validated to form a valid model.

   `self` is explicitly positional-only to allow `self` as a field name.


   .. py:attribute:: model_config

      Configuration for the model, should be a dictionary conforming to [`ConfigDict`][pydantic.config.ConfigDict].


   .. py:attribute:: job_name
      :type:  str | None
      :value: None


      Name of the job (--job-name).


   .. py:attribute:: partition
      :type:  str | None
      :value: None


      Partition to submit the job to (--partition). Multiple partitions can be comma-separated.


   .. py:attribute:: reservation
      :type:  str | None
      :value: None


      Reserve resources from a named reservation (--reservation).


   .. py:attribute:: nodes
      :type:  int | str | None
      :value: None


      Number of nodes to allocate (--nodes). Can be an integer or a range like '2-4'.


   .. py:attribute:: ntasks
      :type:  int | None
      :value: None


      Total number of tasks to launch (--ntasks).


   .. py:attribute:: ntasks_per_node
      :type:  int | None
      :value: None


      Number of tasks per allocated node (--ntasks-per-node).


   .. py:attribute:: cpus_per_task
      :type:  int | None
      :value: None


      Number of CPUs per task (--cpus-per-task).


   .. py:attribute:: mem
      :type:  str | None
      :value: None


      Memory per node (--mem), e.g. '4G', '512M', '0' for all available memory.


   .. py:attribute:: gpus
      :type:  str | int | None
      :value: None


      count', e.g. 'v100:2'.

      :type: Total GPUs for the job (--gpus). Can be a count or 'type


   .. py:attribute:: gpus_per_node
      :type:  str | int | None
      :value: None


      count', e.g. 'a100:4'.

      :type: GPUs per node (--gpus-per-node). Can be a count or 'type


   .. py:attribute:: gres
      :type:  str | None
      :value: None


      2,shard:1'.

      :type: Generic consumable resources (--gres), e.g. 'gpu


   .. py:attribute:: time
      :type:  str | None
      :value: None


      'minutes', 'MM:SS', 'HH:MM:SS', 'D-HH', 'D-HH:MM', 'D-HH:MM:SS'.

      :type: Wall clock time limit (--time). Formats


   .. py:attribute:: begin
      :type:  str | None
      :value: None


      00:00', 'now+1hour'.

      :type: Defer job start until the specified time (--begin), e.g. '2024-01-15T10


   .. py:attribute:: output
      :type:  str | None
      :value: None


      %j (job ID), %x (job name), %A (array master ID), %a (array task ID), %N (node name), %u (user name).

      :type: File path for stdout (--output). Supports replacement symbols


   .. py:attribute:: error
      :type:  str | None
      :value: None


      File path for stderr (--error). Same replacement symbols as output.


   .. py:attribute:: array
      :type:  str | None
      :value: None


      Job array specification (--array), e.g. '0-15', '1,3,5,7', '1-7%2' (max 2 concurrent).


   .. py:attribute:: kill_on_invalid_dep
      :type:  bool | None
      :value: None


      Kill the job if any dependency is invalid (--kill-on-invalid-dep).


   .. py:attribute:: nice
      :type:  int | None
      :value: None


      Scheduling priority adjustment (--nice). Positive values lower priority.


   .. py:attribute:: chdir
      :type:  str | None
      :value: None


      Working directory for the job (--chdir).


   .. py:attribute:: env_path
      :type:  str | None
      :value: None


      Shell command to source before running the job (e.g. for activating a virtual environment) which should be used as 'source env_path'.


   .. py:method:: to_srun_args()

      Return a string of srun arguments for all non-None SLURM fields.

      Fields that are not actual srun directives (``experiment_file``, ``source``)
      are excluded. Boolean fields are rendered as bare flags when ``True`` and
      omitted when ``False``.



   .. py:method:: validate_time_format(value)
      :classmethod:


      Validate SLURM time format.



   .. py:method:: validate_memory_format(value)
      :classmethod:


      Validate SLURM memory format (number with optional K/M/G/T suffix).



   .. py:method:: validate_array_format(value)
      :classmethod:


      Validate SLURM array specification.



   .. py:method:: validate_gpu_spec(value)
      :classmethod:


      Validate GPU specification (count or type:count).
