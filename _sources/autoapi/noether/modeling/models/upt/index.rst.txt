   .. py:method:: compute_rope_args(surface_position_batch_idx, surface_position, surface_position_supernode_idx, query_position)

      Compute the RoPE frequency arguments for the surface_position and query_position. If we don't use RoPE,
      return empty dicts.

      :param surface_position_batch_idx: Batch indices for the surface positions.
      :param surface_position: Surface position coordinates.
      :param surface_position_supernode_idx: Supernode indices for the surface positions.
      :param query_position: Query position coordinates.

      :returns: Dictionary containing the RoPE frequency arguments.
      :rtype: dict[str, torch.Tensor]



   .. py:method:: forward(surface_position_batch_idx, surface_position_supernode_idx, surface_position, query_position)

      Forward pass of the UPT model.

      :param input_position: input coordinates of the surface points.
      :param surface_mask_query: surface mask for the query points, indicating which points are surface points.
      :param surface_position_batch_idx: batch indices for the surface positions, since the surface positions are
                                         a sparse tensor for the supernode pooling.
      :param surface_position_supernode_idx: supernode indices for the surface positions.
      :param geometry_position: geometry position information.
      :param query_position: input coordinates of the query points.

      :returns: dictionary with the output tensors, containing the surface pressure and volume
                velocity.
      :rtype: dict[str, torch.Tensor]
