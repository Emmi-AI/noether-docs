.. py:class:: ShuffleWrapper(config, dataset)

   Bases: :py:obj:`noether.data.base.subset.Subset`


   Shuffles the dataset, optionally with seed.

   .. rubric:: Example

   .. code-block:: yaml

       dataset_wrappers:
           kind: noether.data.base.wrappers.ShuffleWrapper
           seed: 42

   :param config: Configuration for the ShuffleWrapper. See :class:`~noether.core.schemas.dataset.ShuffleWrapperConfig`
                  for available options.
   :param dataset: The dataset to shuffle. Can be a base dataset or an already wrapped dataset.

   :raises ValueError: If the dataset is not an instance of noether.data.Dataset or DatasetWrapper, or if the seed is not an integer or None.
