.. py:function:: validate_path(path, exists = 'must', suffix = None, mkdir = False)

   Converts a string to a Path, validates it, and optionally creates it.

   :param path: The path string to validate.
   :param exists:
                  - "must": Raises FileNotFoundError if the path doesn't exist.
                  - "must_not": Raises FileExistsError if the path already exists.
                  - "any": Performs no existence check.
   :param suffix: If provided, checks if the path ends with this suffix.
   :param mkdir: If True, creates the directory path (like mkdir -p).

   :returns: The validated path.
   :rtype: Path
