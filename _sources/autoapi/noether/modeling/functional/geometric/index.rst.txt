.. py:function:: radius_triton(x, y, r, batch_x = None, batch_y = None, max_num_neighbors = None)

   Find all edges where points in x are within radius r of points in y.

   :param x: Source points, shape (N, D) or flattened (N*D,) with D inferred
   :param y: Target points, shape (M, D) or flattened (M*D,)
   :param r: Radius threshold
   :param max_num_neighbors: Maximum neighbors per target point (default: N)
   :param batch_x: Batch indices for x points, shape (N,)
   :param batch_y: Batch indices for y points, shape (M,)

   :returns:

             - row 0: source indices (from x)
             - row 1: target indices (from y)
   :rtype: Edge index tensor of shape (2, E) where

.. py:function:: knn_triton(x, y, k, batch_x = None, batch_y = None)

   Calculates k-nearest neighbors using a Triton kernel.

   :param x: Reference points (N, D)
   :param y: Query points (M, D)
   :param k: Number of neighbors
   :param batch_x: Optional batch indices for x (N,)
   :param batch_y: Optional batch indices for y (M,)
   :param cosine: If True, uses Cosine distance. False = Euclidean.

   :returns: Indices of the k nearest neighbors for each y (M, K)
